# Draw board surface brief

- Mode: Experience.
- Audience: casual visitors arriving at a public GitHub Pages app who want to draw immediately.
- Primary task: sketch with mouse, touch, or stylus, then explicitly invite an AI companion to add a restrained turn.
- Approved composition: `.impeccable/mocks/approved-board-and-toolbar.png`, with the user's explicit condition that only the board and toolbar remain.
- Memorable moment: the turn button depresses like a physical studio control and the AI's strokes appear point by point before the pencil returns to the visitor.
- Visual world: full-viewport sage drafting board, warm paper, blush inset tool rail, hand-lettered title, mustard/coral/eggplant/sage tools. No room, scenery, outer background, floating card dashboard, or professional editor chrome.
- Component grammar: framed paper canvas; compact board label/status; physical round tools; separated utility actions; prominent rectangular AI-turn button; one focused settings sheet.
- Inventory: drawing canvas, pen, eraser, four colors, undo, redo, clear, export PNG, export SVG, OpenRouter connection/settings, AI-turn action, accessible status.
- Constraints: static hosting, visitor-owned OpenRouter credential, browser-only persistence, no project-funded inference.
